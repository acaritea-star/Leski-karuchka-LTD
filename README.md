# LeskiKaruchka — актуализация от 13.09.2026

React + Vite + TypeScript, Supabase Auth/Postgres/Realtime/Edge Functions и Google Maps. Един сайт, една база, един източник за цената и един GPS изпращач.

Този пакет обновява съществуващия проект `rzjyvxmfqnnxglmgnvma`. Не е начална схема за празна база. Трите миграции и петте Edge Functions вече са приложени в проекта. Новият сайт още не е публикуван на домейна.

## Стартиране

Node.js 22.12 или по-нова поддържана версия:

```sh
npm ci
npm run dev
```

В архива е запазена предоставената публична Vite конфигурация. За друга среда използвай `.env.example` и не поставяй административни ключове във Vite променливи.

```sh
npm run check
npm run lint
```

`check` проверява TypeScript, изпълнява тестовете и генерира `out/`. Готовият `out/` също е включен. Хостингът трябва да връща `index.html` за маршрутите на приложението и да използва HTTPS.

## Къде е описана работата

- `CHANGES.md` — точните променени и нови файлове и предназначението им.
- `VERIFICATION.md` — изпълнени проверки, резултати и ограничения.
- `project_plan.md` — преработен план с отделени реализирани функции и следващи стъпки.
- `deployment/README.md` — последователност за публикуване, оставащи настройки и възстановяване.
- `deployment/file-manifest.json` — машинно проверим списък на разликите спрямо оригиналния архив, включително генерираните файлове.

## Текущи пречки пред реално пускане

Supabase Auth приема входа, но PostgREST отхвърля издадения токен с `PGRST303: JWT issued at future`. Проблемът е възпроизведен и с токен на около четири минути. Не е заобикаляна проверката на токени. Докато това не се отстрани, нормалната работа през API не е потвърдена.

В реалната база има един проверен шофьор и нула автомобили. Администраторът трябва да въведе реалния автомобил и да го свърже с шофьора. Не са създавани измислени оперативни данни.
